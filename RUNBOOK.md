# Runbook

For a material false PASS: preserve the matter directory, verify the audit hash
chain, identify source/model/prompt/rule versions, mark affected outputs for
revalidation, disable the affected path if necessary, add a regression case,
rerun the benchmark, and obtain counsel approval before release.

For provider outages, stale authority, missing parity, incomplete retrieval, or
unresolved disagreement, the correct operational result is `REVIEW_REQUIRED`.
