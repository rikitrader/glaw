## Legal and evaluation posture

This release is a source-backed engineering framework. It does not provide a legal
opinion, create an attorney-client relationship, guarantee enforceability, override
mandatory law, fiduciary duties, court authority, or human counsel requirements.

The benchmark contains 10,000 structured items, but attorney gold labels and
adjudications are not yet populated. Therefore the system has not established an
empirical material-error rate or the target 95% confidence upper bound below 3%.
