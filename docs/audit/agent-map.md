# Agent Map

## Current

- Managing Partner/orchestrator routes matters through a firm roster.
- Specialist capabilities are primarily `SKILL.md` instructions plus CLI tools.
- Legal Governor, conscience, adversarial, oversight, host, MCP, and Extism
  adapters exist in source or executable form.
- Independent Claude/Codex provider records are used for selected verification.

## Missing or not yet unified

- One runtime agent registry with typed input/output contracts.
- Capability-scoped permissions for every agent.
- Per-agent budgets, loop detection, and model policy binding.
- Canonical memory write policy separating facts from inferences.
- Signed skill supply-chain metadata and sandboxed marketplace execution.

## Migration rule

Treat agents as capabilities with contracts, not personas. Preserve existing
skills; normalize and wrap them incrementally.
