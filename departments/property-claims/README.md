# GLAW Property Claims

Additive property-claims department implementing the canonical chain:

`GLAW → Property Claims → Claim Digital Twin → Policy/Law → Evidence/Causation → Building Science → Xactimate/Invoices → Red ↔ Blue → White → Human Review → Defensible Report`

Phase 1 includes typed domain contracts, immutable document registration, policy-first guards, estimate/invoice normalizers, evidence-bound Red/Blue/White issue objects, confidence controls, JSON Schemas, and tests.

Design rule: **FACTS → EVIDENCE → POLICY → LAW → CAUSATION → SCOPE → METHOD → QUANTITY → PRICE → DAMAGES → PAYMENT**.

Unknown information is represented explicitly. No module treats Xactimate pricing as dispositive, treats an invoice as proof of necessity, or labels an anomaly as fraud without sufficient evidence.

The remaining specialist directories and production adapters are staged in `docs/IMPLEMENTATION.md`; this package deliberately uses adapters so existing GLAW architecture is not rewritten.
