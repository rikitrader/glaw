# PCLC — GLAW 50-State Property Claims Legal Compiler

Phase 1 deterministic foundation for source-first, jurisdiction-aware property-claims law. The compiler separates source law, interpreted propositions, safe declarative rules, and claim-specific application. It does not contain invented state law and does not label the 51-jurisdiction registry production-complete.

Implemented: strict legal types, safe DSL without `eval`, temporal and bitemporal range helpers, authority hierarchy, citation verification contract, 51-jurisdiction registry, policy-claim compiler package, and source/provider boundaries.

The registry status is `NOT_STARTED` until official sources are ingested, hashed, verified, compiled, adversarially tested, benchmarked, and human-approved where required.
