# Country dossier index

The dossier template is intentionally data-empty until each country is sourced. Required fields are:

`crisis`, `causes`, `monetary_regime_before`, `inflation`, `fx_system`, `banking_conditions`, `fiscal_conditions`, `reform`, `hanke_position`, `actual_policy`, `outcome`, `long_term_result`, `criticism`, `lessons`.

Target cases: Argentina, Bulgaria, Bosnia, Estonia, Lithuania, Hong Kong, Montenegro, Ecuador, Panama, Zimbabwe, Venezuela, Yugoslavia, Turkey, Lebanon, Iran, Russia, and Indonesia. Missing evidence remains missing; no country comparison is run until critical comparator fields are populated or explicitly marked unavailable.

The active episode index supplied for the Venezuela comparison is in `index.json` and contains 20 episodes. The posture matrix is generated by `src/posture-index.ts`: 20 episodes × 14 postures = 280 auditable cells. Every cell begins empty and `PENDING_SOURCE_REVIEW`.
